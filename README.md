# Brainy Robot – AI Voice-Controlled Learning Assistant for Children

## Overview

Brainy Robot is an AI-powered interactive learning assistant designed to provide an engaging educational experience for children through natural voice-based interaction. The system combines embedded systems, speech recognition, artificial intelligence, and text-to-speech technologies to answer questions, tell stories, conduct quizzes, and support learning activities.

The project aims to create a low-cost educational companion that makes learning more interactive and accessible for young students.

## System Architecture

1. User speaks a question into the microphone.
2. ESP32 captures the audio input.
3. Speech-to-Text service converts audio into text.
4. The text query is sent to an AI model.
5. AI generates an appropriate response.
6. Text-to-Speech converts the response into audio.
7. The speaker outputs the generated response.

---

## Working Principle

The Brainy Robot uses an ESP32-based architecture to capture voice commands from users. Audio data is processed through speech recognition services, allowing the system to understand spoken questions. The recognized text is then forwarded to an AI engine capable of generating informative and age-appropriate responses.

The generated response is converted back into speech and delivered through the speaker, creating a natural conversational experience.
